How to create an App Registration
  1. In Azure Active Directory, go to App registrations → New registration.
  2. Set a redirect URI of type Web (any value, e.g. http://localhost).
  3. Go to Certificates & secrets → New client secret and copy the Value.
  4. In D365 System administration → Azure Active Directory applications, add the Client ID and map to a user with DMF permissions.
